# 🌐 AI Landscape Infographic

Interactive infographic visualizing AI model comparisons across speed, reliability, and multimodal capabilities for mid-2025.

## 📊 Features

- **Speed vs. Reliability Comparison**: Visual scatter plot showing the trade-off between model speed and reliability
- **Detailed Model Comparison Table**: Comprehensive breakdown of 22+ AI models with archetype descriptions, reasoning capabilities, and ideal use cases
- **AI Model Matchmaker**: Describe your task and get AI-powered recommendations for the best model
- **AI Prompt Enhancer**: Improve your prompts with model-specific optimization
- **Multimodal Revolution**: Overview of models supporting text, images, audio, and video
- **Context Window Comparison**: Visualize the vast differences in model memory capacity

## 📝 Usage

Simply open `index.html` in any modern web browser. The application is entirely self-contained with no build process required.

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/caseypotatowebb-cpu/ai-landscape-infographic.git
   ```

2. Open index.html in your browser:
   ```bash
   cd ai-landscape-infographic
   open index.html
   ```

## 🔑 API Configuration

To use the interactive Gemini-powered features (Model Matchmaker & Prompt Enhancer), you'll need to add your Gemini API key in the application settings.
